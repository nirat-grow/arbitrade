## 🛠️ How It Works in Code
- **Backend File:** `backend/verifiedTransactions.js`
- **Frontend Utility:** `frontend-v2/src/utils/verifiedTransactions.js`
- **Formatting Helper:** `frontend-v2/src/utils/formatters.js` (`getDeterministicTxHash`)
- When any trade is clicked, the system uses the trade's `network` and `pair` to retrieve a verified on-chain transaction hash.
- When the user clicks **"Explorer"**, the corresponding block explorer opens showing **Status: Success** and real DEX multicall token transfer events.
